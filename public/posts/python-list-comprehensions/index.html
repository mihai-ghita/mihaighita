Mastering Python List Comprehensions

20 Feb 2025 · 1 min read

A deep dive into Python list comprehensions with practical examples and best practices.

List comprehensions are one of Python’s most elegant features. They allow you to create lists in a concise, readable way. Let me show you some examples.

Basic Syntax

The basic syntax of a list comprehension is:

[expression for item in iterable]

Here’s a simple example that squares numbers:

squares = [x**2 for x in range(10)]
# Result: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

With Conditions

You can add conditions to filter elements:

even_squares = [x**2 for x in range(10) if x % 2 == 0]
# Result: [0, 4, 16, 36, 64]

Nested Comprehensions

For more complex operations, you can use nested comprehensions:

matrix = [[i*j for j in range(3)] for i in range(3)]
# Result: [[0, 0, 0], [0, 1, 2], [0, 2, 4]]

Real-World Example

Here’s a practical example that processes user data:

users = [
    {"name": "Alice", "age": 25, "active": True},
    {"name": "Bob", "age": 30, "active": False},
    {"name": "Charlie", "age": 22, "active": True}
]

active_user_names = [user["name"] for user in users if user["active"]]
# Result: ["Alice", "Charlie"]

List comprehensions are not just shorter—they’re often faster than equivalent loops because they’re optimized at the C level in Python’s implementation.
