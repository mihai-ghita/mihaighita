## Project Overview

Personal portfolio and blog website for Mihai Ghita, built with Hugo static site generator and deployed to GitHub Pages at mihaighita.org. The site features a modern design with a purple gradient theme, blog functionality, and will include portfolio/project showcases.

## Repository Structure

### Hugo Architecture
- `config.yaml` - Hugo site configuration, menu structure, and site parameters
- `layouts/` - HTML templates for different page types
  - `index.html` - Homepage template with hero and blog posts
  - `_default/baseof.html` - Base template with common structure
  - `_default/single.html` - Individual page template
  - `_default/list.html` - List page template (categories, tags)
  - `posts/single.html` - Blog post template
  - `partials/` - Reusable components (header, footer, social links, post cards)
- `assets/css/` - Source CSS files
  - `main.css` - Core styling for layout, navigation, hero, footer
  - `blog.css` - Blog-specific styling for posts and cards
- `content/` - Markdown content files
  - `_index.md` - Homepage content
  - `about.md` - About page
  - `contact.md` - Contact page
  - `posts/` - Blog posts directory
- `static/` - Static assets (images, CNAME, .nojekyll)
  - `imgs/` - Profile images and assets
  - `CNAME` - Custom domain configuration
- `public/` - Generated site output (auto-generated by Hugo)
- `data/social.yaml` - Social media links configuration

### Key Files
- `CNAME` - Custom domain configuration (mihaighita.org) in root and static/
- `todo.txt` - Tracked improvements and feature additions
- `.hugo_build.lock` - Hugo build lock file
- `.gitignore` - Git ignore patterns

## Development Workflow

### Local Development
```bash
# Start Hugo development server
hugo server -D

# Build for production
hugo

# Deploy (public/ folder to GitHub Pages)
git add public/
git commit -m "Deploy site"
git push
```

### Hugo Commands
- `hugo new posts/my-post.md` - Create new blog post
- `hugo new content/page-name.md` - Create new page
- `hugo --buildDrafts` or `hugo -D` - Build including draft content

## Deployment

The site is deployed via GitHub Pages:
- Repository: https://github.com/mihai-ghita/mihaighita
- Custom domain: mihaighita.org (configured via CNAME file)
- Deploy the `public/` directory contents to GitHub Pages
- `.nojekyll` file prevents Jekyll processing on GitHub Pages

## Features

### Blog Features
- **Featured Images**: Optional images for post cards and single posts
- **Summaries**: Custom descriptions or auto-generated from content
- **Reading Time**: Automatic calculation based on word count (200 wpm)
- **Word Count**: Displayed on single post pages
- **Categories & Tags**: Taxonomies for content organization
- **Responsive Design**: Mobile-first with 4 breakpoints
- **Responsive Images**: srcset and picture element support
- **Touch Targets**: All interactive elements minimum 44px
- **Smooth Scrolling**: CSS scroll-behavior for anchor links
- **Mobile Menu**: Animated hamburger menu with slide-down

See detailed documentation in `docs/`:
- `FEATURED_IMAGES.md` - Featured image usage
- `SUMMARIES.md` - Writing effective summaries
- `READING_TIME.md` - Reading time estimates
- `RESPONSIVE_DESIGN.md` - Responsive design implementation

## Design System

### Colors
- Primary gradient start: `#667eea` (purple-blue)
- Primary gradient end: `#764ba2` (deep purple)
- Text dark: `#2d3748`
- Text medium: `#4a5568`
- Text light: `#718096`
- Background light: `#f7fafc`
- Border color: `#e2e8f0`

### Typography
- Font family: System font stack (Apple System, Segoe UI, Roboto, etc.)
- Hero h1: 52px (mobile: 36px)
- Page h1: 42px (mobile: 32px)
- h2: 32px (mobile: 24px)
- h3: 24px (mobile: 20px)
- Body: 18px (mobile: 16px)
- Tagline: 20px

### Responsive Breakpoints
- Mobile: 600px and below (hamburger menu, single column)
- Tablet: 601px to 1024px (horizontal menu, 2-column grid)
- Desktop: 1025px to 1439px (1200px containers, 3-column grid)
- Large desktop: 1440px+ (1400px containers, enhanced spacing)

### Component Patterns
- Border radius: 15-20px for cards, 50px for buttons
- Box shadow: `0 10px 30px rgba(0, 0, 0, 0.2)` for elevation
- Transitions: `0.3s ease` for hover effects
- Animations: fadeIn (1s ease-in) for page loads

## Development Guidelines

### When Adding Features
1. Maintain the purple gradient theme consistency
2. Ensure mobile responsiveness (test at 600px breakpoint)
3. Add ARIA labels for accessibility
4. Use semantic HTML5 elements
5. Keep animations subtle and performance-friendly
6. Follow existing CSS naming conventions

### CSS Organization
- Global styles in `main.css`
- Blog-specific styles in `blog.css`
- Use CSS custom properties for theme values (future improvement)
- Mobile-first approach with max-width media queries

### Content Guidelines
- Blog posts in `content/posts/`
- Use Hugo front matter: title, date, categories, tags, draft status
- Add `description` field for custom post summaries (120-160 characters recommended)
- Use `<!--more-->` divider for natural summary breaks
- Add featured images using `featured_image: "/imgs/your-image.jpg"` parameter
- Optional responsive images: `featured_image_srcset`, `featured_image_mobile`, `featured_image_tablet`
- See `docs/SUMMARIES.md` for summary best practices
- See `docs/FEATURED_IMAGES.md` for featured image documentation
- See `docs/RESPONSIVE_DESIGN.md` for responsive image guidelines
